# ⚽ MatchMind — Agentic Match Intelligence Studio

**Inside the Game: Developer Hackathon (Microsoft × Premier League) submission.**

MatchMind turns a live stream of synthetic football events into explainable
match intelligence: real-time stats, tactical explanations, multi-language
narration and personalized viewing experiences — plus a player **Load & Risk
Monitor** grounded in sports science (ACWR).

> **Synthetic data only.** Every club, player, event and statistic in this
> project is fictional and generated by our own simulation engine. No real
> Premier League data is used.

## The five-stage pipeline

| Stage | Component | Status |
|---|---|---|
| 1. Ingest | Synthetic match engine streaming timestamped events | ✅ v1 |
| 2. Interpret | Stats/state aggregation (momentum, xG, pass difficulty, workload) | 🔜 |
| 3. Explain | Analyst agent: *why* a moment matters | 🔜 |
| 4. Render | Live 2D pitch + broadcast-style overlays (React) | 🔜 |
| 5. Personalize | Director agent: Analyst / Casual / Commentator / Player-Focus modes, multi-language | 🔜 |

## Architecture (target)

- **Azure AI Foundry** — model hosting (gpt-4o / gpt-4o-mini) + evals
- **Microsoft Agent Framework** — multi-agent orchestration (Interpreter,
  Analyst, Narrator, Director, Load & Risk Monitor)
- **MCP server** — match-state tools exposed to agents
- **Azure Container Apps** (backend) + **Azure Static Web Apps** (frontend)
- Built with **GitHub Copilot** assistance

## Quickstart (simulator)

```bash
cd backend
python -m matchmind.generate_match --home THU --away NBF --seed 42 --out ../data
```

Outputs an event stream (`*_events.jsonl`) and match metadata (`*_meta.json`).

## Responsible AI note

The Load & Risk Monitor is **decision support, not medical advice**. It flags
workload patterns (acute:chronic workload ratio, sprint density, fatigue
proxies) on synthetic athletes for illustrative purposes only.
